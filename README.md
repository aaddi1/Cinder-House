# Cinder-House
Cinder House — Boutique Hotel Web Experience  Designed and developed a modern boutique hotel website focused on creating an immersive and premium digital experience.  The project combines HTML, CSS, JavaScript, Three.js, responsive design, 3D visuals, animations, and a Liquid Glass-inspire Built from scratch | Designed &amp; Developed by Aryan Sharma

## Preview

[Live Website](https://aaddi1.github.io/Cinder-House/)

## About

Cinder House is a premium boutique hotel website created to explore
cinematic web design, interactive 3D visuals, animations, and modern UI.

## Features

- Responsive design
- Three.js 3D visuals
- Interactive animations
- Liquid Glass-inspired UI
- Hotel rooms showcase
- Amenities and dining sections
- Gallery
- Interactive contact options

## Technologies

- HTML5
- CSS3
- JavaScript
- Three.js
