> **Cinder House** is an immersive, modern boutique hotel and live-fire culinary web experience in Taj Ganj, Agra. Built completely from scratch with a custom **Three.js WebGL particle & lighting engine**, **Apple-inspired Liquid Glass UI**, smooth parallax scroll kinematics, and interactive hospitality booking components.

### 1. 🌐 Real-Time 3D WebGL & Ember Particle Simulation
* **Ember Physics Engine:** GPU-accelerated particle buffer geometry simulating rising embers with random velocity vectors, opacity oscillations, and custom canvas glow textures.
* **Abstract 3D Torus Knot Emblem:** High-precision metallic PBR mesh with dynamic point lights responding in real-time to user scroll progress and mouse coordinates.
* **Smooth Camera Kinematics:** Frame-interpolated 3D camera transitions that react smoothly to user interaction.

### 2. 💎 Apple Clear Liquid Glass UI
* **Backdrop Filter Compositing:** Multi-layer frosted glass cards with specular gloss highlights (`backdrop-filter: blur(22px) saturate(125%)`).
* **Micro-Interactions:** Fluid hover lifts, soft ember glow borders, and elegant typography blending Fraunces serif with Archivo.
* **Warm Amber Lighting Aesthetic:** Evokes the warmth of live-fire coals, wood-fired hearths, and intimate boutique hospitality.

### 3. 🛎️ Hospitality Suite & Features
* **Five Curated Rooms Upstairs:** Detailed showcase of The Hearth Room, The Copper Suite, The Ember Loft, The Smoke House, and The Lantern Room.
* **Live-Fire Kitchen Dining:** Interactive course tabs for Fire Starters, From the Coals, Embers & Sweets, and The Cellar.
* **Interactive Reviews & Location:** Guest testimonial cards, Google Maps integration, and direct reservation inquiries.

## 🚀 Quick Start & Local Preview

To explore and run Cinder House locally:

```bash
# 1. Clone the repository
git clone https://github.com/aaddi1/Cinder-House.git

# 2. Navigate to project root
cd Cinder-House

# 3. Start a local server
python3 -m http.server 8000
# or
npx serve .

# 4. Open in browser
open http://localhost:8000
```
